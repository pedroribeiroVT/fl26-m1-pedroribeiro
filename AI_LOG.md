# AI_LOG.md

I wrote the implementation myself first, then used AI to go back over the finished code against M1_Specification_v1.0.pdf for all the different files. The design and most of the code itself were mine, AI was used as a second pass to catch anything that didn't line up with the specification and would make small changes for any bugs I didn't catch.

To save time, I also used AI to help write some of the test cases in tests/. I told it what needed to be tested for each function and then it would write the functions that I asked it too. It did not make decisions on what would be tested.
